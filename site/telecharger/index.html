Télécharger belprise

Version %LATEST_VERSION%, publiée le %LATEST_DATE%. Nouveautés : toutes les versions.

Hébergement mutualisé ou serveur Apache

Archive belprise-%LATEST_VERSION%.zip

Puis suivez le guide d’installation. Pour vérifier que l’archive est intacte, téléchargez aussi son empreinte (.sha256, sur la page de la version), puis :

shasum -a 256 -c belprise-%LATEST_VERSION%.zip.sha256

Docker (VPS, NAS)

L’image contient FFmpeg, l’envoi des e-mails par SMTP et la tâche planifiée. Avec le fichier compose.yml :

docker compose up -d

Image : ghcr.io/belprod/belprise:%LATEST_VERSION% (ou :3 pour suivre les mises à jour de la 3).

Mettre à jour

php app/bin/update.php belprise-%LATEST_VERSION%.zip

Avec Docker : docker compose pull && docker compose up -d. Votre installation vous prévient elle-même des nouvelles versions, dans l’exploitation.

La version 3.0.0, la première à installer soi-même, est en préparation.

Suivez son avancement sur GitHub (bouton « Watch », puis « Releases ») ; en attendant, la démo montre belprise en action.
